# 제주 해안 지킴이 지도 (팀 제주쓰담쓰담)

2026 제주 환경 해커톤 출품작. 쓰레기 **양**이 아니라 **생물에게 위험한 순서**로 해안 수거 우선순위를 보여주는 웹앱입니다.

## 화면
1. **위험도 지도** – 제주 수거량 추이(2009~2023), 해안별 위험 지수 지도, 실시간 위험 순위, 기관·언론 정화 기록, 공공데이터로 본 개수 vs 위험 지수 비교
2. **쓰레기 제보** – 사진 업로드 → AI(Gemini) 종류 판별 → 제보 → 해안 스탬프
3. **우선 수거 리포트** – 위험 지수 상위 지점, 바다환경지킴이·행정 전달용 CSV
4. **가중치 검증** – 가중치 슬라이더, 360개 가중치·보정 조합 민감도 분석, 요소 간 중복 점검

## 점수
- 위험 지수 = 보정 위해성 × (1 + 돌고래) × 마을어장 × 계절
- 보정 위해성 = (근거별 위해성 합 + 1×2) ÷ (근거 수 + 1) — 근거가 적은 지점이 한 건으로 튀지 않게 중간값(2) 쪽으로 당기는 축소 추정
- 위해성: 폐어구·로프·낚싯줄 3 / 플라스틱·스티로폼 2 / 해조류·기타 1 (순위 척도. 근거: Wilcox 외 2016, *Marine Policy* 65 — 전문가 274명 평가에서 버려진 어구가 해양생물 위협 1위)
- 돌고래: 대정읍 1.0 (2025 해양생물보호구역 신도리), 안덕면·구좌읍 0.5 (2026 보도)
- 마을어장 500m 이내 ×1.5, 겨울 북서계절풍 토글 시 북·서 해안 ×1.2
- 근거 수 = 공공 조사 + 기관·언론 기록 + 시민 제보 건수

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```
AI 판별을 쓰려면 `.streamlit/secrets.toml`에 `GEMINI_API_KEY = "..."`를 넣으세요 (Streamlit Cloud는 앱 설정의 Secrets).
무료 한도 보호: 분당 5회·하루 100회 상한, 같은 사진은 재호출하지 않습니다.
