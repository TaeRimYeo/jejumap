# 제주 해안 지킴이 지도 (팀 제주쓰담쓰담)

2026 제주 환경 해커톤 출품작. 쓰레기 **양**이 아니라 **생물에게 위험한 순서**로 해안 수거 우선순위를 보여주는 웹앱입니다.

## 화면
1. **위험도 지도** – 제주 수거량 추이(2009~2023), 해안별 위험 지수 지도, 실시간 위험 순위, 기관·언론 정화 기록, 공공데이터로 본 개수 vs 위험 지수 비교, **해안 106개 구역 확인 공백 표시**
2. **쓰레기 제보** – 사진 업로드 → AI(Gemini) 종류 판별 → 제보 → 해안 스탬프
3. **우선 수거 리포트** – 위험 지수 상위 지점, 지킴이·행정 전달용 CSV, 수거 완료 처리(되돌리기 포함), 확인 공백 구역 순찰 목록(CSV), 재확인 권장 지점
4. **가중치 검증** – 가중치 슬라이더, 720개 가중치·보정·반감기 조합 민감도 분석(버튼으로 실행), 요소 간 중복 점검

## 점수
- 현재 위험 지수 = 보정 위해성 × (1 + 돌고래) × 마을어장 × 계절 × 최신성
- 최신성: 근거가 오래될수록 가볍게 (반감기 공공 조사 3년, 기관 기록·시민 제보 180일)
- 수거 완료 처리: 완료일 이전 근거는 현재 점수에서 빠지고, 이후 새 근거가 들어오면 다시 순위에 올라옴
- 보정 위해성 = (근거별 위해성 합 + 1×2) ÷ (근거 수 + 1) — 근거가 적은 지점이 한 건으로 튀지 않게 중간값(2) 쪽으로 당기는 축소 추정
- 위해성: 폐어구·로프·낚싯줄 3 / 플라스틱·스티로폼 2 / 해조류·기타 1 (순위 척도. 근거: Wilcox 외 2016, *Marine Policy* 65 — 전문가 274명 평가에서 버려진 어구가 해양생물 위협 1위)
- 돌고래: 대정읍 1.0 (2025 해양생물보호구역 신도리), 안덕면·구좌읍 0.5 (2026 보도)
- 마을어장 500m 이내 ×1.5, 겨울 북서계절풍 토글 시 북·서 해안 ×1.2
- 근거 수 = 공공 조사 + 기관·언론 기록 + 시민 제보 건수

## 확인 공백 ("제보 없음 ≠ 깨끗함")
- 제주 본섬 해안을 마을어장 지선 106개 구역(어장정보도 마을어업, 추자도 제외)으로 나눔 → `zones.geojson`
- 근거(조사·기록·제보)는 자기 위치로, 수거 완료는 지점 위치로 가장 가까운 구역(1.5km 이내)에 붙여 구역별 마지막 확인일 계산
- 순찰했는데 쓰레기가 없으면 '순찰 확인(이상 없음)'으로 기록 → 그 구역도 확인된 것으로 처리 (점수에는 영향 없음)
- 상태: 확인 기록 없음 / 오래전 확인(180일 초과) / 최근 확인
- 순찰 순서: 확인 기록 없음 먼저, 같은 상태 안에서는 민감도(돌고래·마을어장·겨울 북서풍) 높은 곳 먼저

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```
AI 판별을 쓰려면 `.streamlit/secrets.toml`에 `GEMINI_API_KEY = "..."`를 넣으세요 (Streamlit Cloud는 앱 설정의 Secrets).
무료 한도 보호: 분당 5회·하루 100회 상한, 같은 사진은 재호출하지 않습니다.
